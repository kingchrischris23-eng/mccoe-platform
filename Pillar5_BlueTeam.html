Incident Response — NIST Playbook
Incident response follows the NIST framework: Preparation, Detection, Containment, Eradication, Recovery, and Lessons Learned. Apply it to the Equifax breach.
NIST Incident Response Framework
1. PREPARATION
Before an incident: establish IR team, create playbooks, deploy monitoring tools, train staff, define communication plan
2. DETECTION
Identify that an incident has occurred: SIEM alerts, user reports, anomaly detection, threat intel feeds
3. CONTAINMENT
Stop the bleeding: isolate affected systems, block malicious IPs/domains, disable compromised accounts, preserve evidence
4. ERADICATION
Remove the threat: delete malware, patch vulnerabilities, close attack vectors, rotate compromised credentials
5. RECOVERY
Restore operations: verify clean systems, restore from backups, monitor for re-infection, gradual return to normal
6. LESSONS LEARNED
Post-incident review: what went wrong, what worked, update playbooks, brief leadership, implement improvements
