PHASE 01 OF 05
Reconnaissance
Gather intelligence on the target without making direct contact. Build your picture from public sources before sending a single packet.
? Legal & Ethical Boundaries ? Read Before You Start
You may NEVER scan, probe, or exploit any system without explicit written permission
You may NEVER use these tools on school, workplace, or public networks without authorization
ALWAYS use TryHackMe or HackTheBox authorized machines ? or your own isolated VirtualBox VM
ALWAYS document your authorization before beginning any real-world penetration test
Report every vulnerability you find ? withholding findings is unethical and potentially illegal
Responsible disclosure: if you find a real vulnerability, report it to the organization privately ? not on social media

PHASE 02 OF 05
Scanning & Enumeration
Actively probe the target to map live hosts, open ports, running services, and known vulnerabilities. Go from a name to a full attack surface.
Types of Scanning
Scan TypePurposeTool
Host DiscoveryFind which IP addresses are live on the networkNmap ping sweep
Port ScanningIdentify which TCP and UDP ports are open on a hostNmap SYN scan
Service / VersionDetermine what software runs on each open portNmap version detection
OS FingerprintingGuess the operating system from network response patternsNmap OS detection
Vulnerability ScanningMatch discovered services to known CVEs in the NVD databaseNessus, Nikto, OpenVAS
Web App ScanningFind SQL injection, XSS, and misconfigurations on web targetsNikto, Burp Suite
Common Nmap Scan Modes
ModeWhat It Does
Basic port scanScans the 1,000 most common TCP ports on the target host
Version detection (-sV)Identifies software name and version on each open port
OS detection (-O)Attempts to fingerprint the operating system
Full pentest scan (-sV -O -sC)Version, OS, and default NSE scripts ? standard starting point
All ports (-p-)Scans all 65,535 TCP ports ? slower but thorough
Ping sweep (-sn)Finds all live hosts on a subnet without port scanning
Real-World Connection
? COLONIAL PIPELINE 2021 ? SCANNING PHASE
DarkSide affiliates scanned the internet for exposed VPN endpoints belonging to Colonial Pipeline. They found a legacy VPN account ? no MFA, password likely reused from a prior breach ? that was still active and reachable. That single open port and single weak credential was the entire entry point for a $4.4 million ransom attack that shut down fuel supplies to 17 states for six days.

Real-World Connection
? EQUIFAX 2017 ? EXPLOITATION PHASE
Attackers exploited CVE-2017-5638 ? a critical remote code execution flaw in Apache Struts. The CVE was published March 7, 2017 with a patch available the same day. Equifax was breached on May 13, 2017 ? 69 days after the patch was released. The exploit required zero authentication and could be triggered with a single crafted HTTP request. Result: 147 million Americans had their Social Security numbers, birthdates, and financial data stolen.

PHASE 04 OF 05
Maintaining Access
Ensure continued entry even after reboots, patches, or if the original vulnerability is closed. Move laterally. Escalate privileges. Stay invisible.
Key Post-Exploitation Concepts
ConceptDefinitionExample
PersistenceMechanisms that survive system reboots and session timeoutsRegistry startup keys, scheduled tasks, backdoor user accounts
Lateral MovementMoving from the initial host to other systems on the networkPass-the-hash, Remote Desktop pivoting, SMB share access
Privilege EscalationGaining higher permissions than initially obtainedEscalating from standard user to root or SYSTEM
Command and Control (C2)Maintaining a communication channel for attacker instructionsReverse shell, Metasploit multi-handler, Cobalt Strike
PivotingUsing a compromised host to reach otherwise inaccessible systemsPort forwarding through an active Meterpreter session
Living Off the LandUsing built-in OS tools instead of custom malware to avoid detectionPowerShell, WMI, certutil ? all built into Windows
Real-World Connection
? SOLARWINDS 2020 ? PERSISTENCE PHASE
After gaining initial access via the poisoned Orion software update, attackers maintained presence for 9 months across approximately 100 high-value targets including US Treasury, Commerce, and Homeland Security departments. They used SAML token forgery for persistent cloud access, scheduled tasks for local system persistence, and lived off the land ? using PowerShell, WMI, and other built-in Windows tools to avoid triggering antivirus. Some organizations did not discover the compromise for over a year.
