📋 Instructor Cheat Sheet

Quick reference for all tools, CVEs, frameworks, and commands used in the program

NMAP COMMANDS
nmap -sn 172.20.0.0/24Ping sweep — find live hosts
nmap -sV -sC -O <ip>Version, scripts, OS detection
nmap -p- <ip>Scan all 65535 ports
nmap --script vuln <ip>Run vulnerability scripts
nmap -oN scan.txt <ip>Save output to file
METASPLOIT COMMANDS
msfconsole -qLaunch Metasploit (quiet)
search vsftpdSearch for module
use <module path>Select exploit module
set RHOSTS <ip>Set target IP
run / exploitExecute the exploit
sessions -i <id>Interact with shell session
WEB ATTACK TOOLS
SQLmap
sqlmap -u "url?id=1" --dbsList databases
sqlmap -u "url" -D db --dumpDump table data
Nikto
nikto -h http://<ip>Web vulnerability scan
Gobuster
gobuster dir -u <url> -w /usr/share/wordlists/dirb/common.txtDirectory brute-force
PASSWORD ATTACKS
Hydra
hydra -l admin -P rockyou.txt ftp://<ip>FTP brute force
hydra -l root -P rockyou.txt ssh://<ip>SSH brute force
Common Wordlists (in Kali)
